======================================================================
《成交 我的慢活日常》專題網站 - images 資料夾圖片替換說明
======================================================================

各位同學好！
本資料夾供存放本專題作品的正式劇照、主視覺海報、分鏡手稿與幕後照片。
目前網站使用自然米色純色區塊作為素材預留位置，避免誤用網路外部圖片。

當正式素材拍攝或製作完成後，請將檔案儲存在此資料夾，並依下方建議檔名命名：

1. 主視覺海報 (Poster)
   - 建議檔名：images/poster.jpg
   - 建議比例：直式 4:5 或 2:3
   - 使用位置：index.html（首頁主視覺區）、film.html（作品規格區）

2. 故事場景與綠洲劇照 (Stills)
   - 建議檔名：images/still-lake.jpg（帝國製糖廠星泉湖風景）
   - 建議檔名：images/still-camera.jpg（主角帶著相機拍照的特寫）
   - 建議檔名：images/still-jogger.jpg（與慢跑男子相遇的場景）
   - 建議比例：橫式 16:9 或 3:2
   - 使用位置：about.html、index.html

3. 幕後花絮照片 (Behind the Scenes)
   - 建議檔名：images/bts-01.jpg（劇組器材架設）
   - 建議檔名：images/bts-02.jpg（導演張紫珊現場走位指導）
   - 建議檔名：images/bts-03.jpg（拍攝現場台中糖廠氛圍）
   - 建議比例：橫式 16:10 或 4:3
   - 使用位置：behind-scenes.html

4. 分鏡手稿 (Storyboards)
   - 建議檔名：images/storyboard-01.jpg（場景一：辦公桌前的壓力）
   - 建議檔名：images/storyboard-02.jpg（場景二：走入台中糖廠步道）
   - 建議檔名：images/storyboard-03.jpg（場景三：按下快門的那一刻）
   - 建議比例：橫式 16:9
   - 使用位置：behind-scenes.html

【替換程式碼方式】：
在對應的 HTML 檔案中，找到有 `<!-- 圖片替換位置 -->` 註解處，
將預留區塊替換為 `<img>` 標籤，例如：
<img src="images/poster.jpg" alt="《成交 我的慢活日常》電影官方海報" class="poster-img">

如有任何問題，請隨時參考各 HTML 檔案中的註解說明！
